# CS2 Lineups Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** iPad-Web-App, die in vier Tipps (Seite → Map → Punkt auf dem Radar → Video) zum passenden Mirage-Smoke/-Molly-Ausschnitt führt.

**Architecture:** Statische React-App ohne Server. Alle Lineups stehen typisiert in `src/data/lineups.ts`. Der Bildschirm ergibt sich allein aus dem URL-Hash (`#/t/mirage/<spotId>`), dadurch funktionieren Neuladen, Wischgeste zurück und Zurück-Pfeil ohne Verlauf. Das Video ist ein `youtube-nocookie`-iframe mit `start`/`end`.

**Tech Stack:** Vite 6, React 18, TypeScript 5, vite-plugin-pwa, Vitest + Testing Library (jsdom). Versionen und Konfiguration wie `Desktop\Meine Programme\Impostor`.

**Spec:** `docs/superpowers/specs/2026-11-16-cs2-lineups-design.md`

## Review Focus

1. **Direktlink/Neuladen** auf `#/ct/mirage/<id>` (Homescreen-App wird oft mitten im Ablauf neu gestartet) → öffnet direkt dieses Lineup. Test in Task 3.
2. **Veraltete Spot-ID im Hash** (Spot nach Datenänderung umbenannt/gelöscht) → zeigt die Karte dieser Seite statt Absturz oder weißer Seite. Test in Task 2 und 3.
3. **Inaktive oder unbekannte Map im Hash** (`#/t/inferno`, `#/t/xyz`) → Map-Pool dieser Seite. Test in Task 2.
4. **Mehrere Lineups mit derselben Landestelle** (zweimal T „Mid Window“) → ein Punkt, Tipp öffnet Auswahl, jede Variante mit einem weiteren Tipp erreichbar. Test in Task 3.
5. **iPad im Hochformat / Größenwechsel** → Punkte bleiben auf ihrer Stelle im Radar, weil sie in Prozent in einem quadratischen Container liegen. Rendertest prüft `left`/`top` in `%` in Task 3, Sichtprüfung in Task 4.

**Files:**

**Interfaces:**
- Produces in `src/data/types.ts`:
  ```ts
  export type Side = "t" | "ct";
  export type NadeType = "smoke" | "molly";
  export type MapInfo = { id: string; name: string; radar?: string; active: boolean };
  export type Spot = {
    id: string; map: string; side: Side; type: NadeType;
    name: string; label: string; area: "A" | "Mid" | "B";
    x: number; y: number;            // Landestelle in % des Radarbilds (0–100)
    videoId: string; start: number; end: number; // Sekunden
    text?: string;
  };
  ```
- Produces in `src/data/lineups.ts`: `export const MAPS: MapInfo[]`, `export const SPOTS: Spot[]`, `export function validate(maps: MapInfo[], spots: Spot[]): string[]` (Liste von Fehlermeldungen, leer = gültig).
- Produces in `src/route.ts`:
  ```ts
  export type Route =
    | { screen: "side" }
    | { screen: "maps"; side: Side }
    | { screen: "map"; side: Side; map: string }
    | { screen: "spot"; side: Side; map: string; spot: string };
  export function parseRoute(hash: string, maps: MapInfo[], spots: Spot[]): Route;
  export function toHash(route: Route): string;   // "#/", "#/t", "#/t/mirage", "#/t/mirage/<id>"
  export function parent(route: Route): Route;
  ```
