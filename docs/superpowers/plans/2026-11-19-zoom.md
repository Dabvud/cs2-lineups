# Zoom beim Gedrückthalten Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lineup-Bilder zoomen beim Gedrückthalten an der Fingerstelle 2,5-fach, an Ort und Stelle.

**Architecture:** Neue Komponente `ZoomImage` kapselt Rahmen, Halte-Timer und Zoom; `LineupScreen` nutzt sie für beide Bilder.

**Tech Stack:** React + TypeScript, Vitest + Testing Library.

**Spec:** `docs/superpowers/specs/2026-11-19-zoom-design.md`

## Global Constraints
- Werte: Haltezeit 250 ms, Abbruch ab 10 px Bewegung, Faktor 2,5.
- `alt`-Texte der Bilder bleiben unverändert (bestehende Tests nutzen sie).

## Review Focus
- Wischen über ein Bild (Scrollen am iPad hochkant) darf nicht zoomen. Test „bricht bei Bewegung vor Ablauf ab“.
- Rahmengröße 0 (Bild noch nicht geladen) darf kein `NaN%` erzeugen. Test mit 0-Rect.
- Loslassen außerhalb des Bildes beendet den Zoom (Listener am `window`). Test.

### Task 1: ZoomImage

**Files:**
- Create: `src/components/ZoomImage.tsx`

**Interfaces:**
- Produces: `export default function ZoomImage({ src, alt }: { src: string; alt: string })` rendert `<div class="zoom-frame"><img class="shot" …/></div>`.

- [ ] **Step 1: Tests (fake timers, `getBoundingClientRect` des Rahmens gemockt auf 0/0/200/100)**
  - „zoomt nach 250 ms an der Fingerstelle“: `pointerDown` bei (50, 25) → nach 249 ms keine Klasse `zoomed`, nach 250 ms Klasse `zoomed` und `transformOrigin` = `"25% 25%"`.
  - „folgt dem Finger“: danach `pointerMove` auf `window` bei (150, 75) → `"75% 75%"`.
  - „loslassen beendet den Zoom“: `pointerUp` auf `window` → keine Klasse `zoomed`.
  - „bricht bei Bewegung vor Ablauf ab“: `pointerDown` (50,25), `pointerMove` (50,40), 300 ms → keine Klasse `zoomed`.
  - „kein NaN bei Rahmengröße 0“: Rect 0×0 → nach Halten `transformOrigin` ohne `NaN`.
